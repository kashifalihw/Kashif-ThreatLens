About Kashif ThreatLens

Project Overview

Kashif ThreatLens is a cybersecurity web application inspired by VirusTotal. The platform allows users to upload files, analyze threats, generate SHA-256 hashes, monitor suspicious files and maintain scan history.


Key Features

✅ File Upload Scanning
✅ SHA-256 Hash Generation
✅ Threat Score Detection
✅ Scan Progress Tracking
✅ Download Scan Reports
✅ History Management
✅ Clear History Feature


Technologies Used

HTML5
CSS3
JavaScript (ES6)
Node.js
Express.js
Local Storage


Purpose

This project was developed for learning cybersecurity concepts and demonstrates how file analysis systems such as VirusTotal work at a basic level.


Developer

Developed by Kashif as a Computer Science Cybersecurity Project.
